# 隐藏系统任务栏与 DeskBox 快捷访问栏

## 用户需求与已确认选择
行为设置增加“隐藏任务栏”，启用时隐藏 Windows 任务栏，显示 DeskBox 快捷访问栏；取消勾选或退出后恢复原任务栏。用户已确认：每个原本有任务栏的显示器各显示一条；普通窗口下常驻，所在屏幕进入全屏应用时隐藏。全屏退出后恢复快捷栏。

## 实现路径选择
推荐原生独立快捷栏窗口配合 Windows AppBar 工作区与单独恢复守护：能够服务普通窗口、多屏与可靠退出恢复，但需要验证 Explorer 重启、DPI 和窗口工作区。
仅放在桌面覆盖层实现较简单，但普通软件会覆盖快捷栏，不符合已选行为。不采用。
直接在 Windows 任务栏内部注入或修改 Explorer 会依赖系统内部细节，不采用。

## 设置、数量与布局
开关默认关闭。行为页增加“隐藏任务栏”及其关联的快捷栏显示数量，支持整数 10 到 MAX，以及 MAX 自动档，默认 12；关闭时保留快捷栏内容与数量设置。MAX 在每个屏幕独立计算：max(12, floor(屏幕逻辑宽度 × 0.68 / (图标单元宽度 + 间距)))。图标单元包含图标内边距，初始为 60 个逻辑像素，其中图标 48；间距为 12。栏左右边距各为半个间距，保证布局宽度与公式一致。多屏不同 DPI 时统一先换算 CSS/逻辑像素，不能混用物理像素。
快捷栏在屏幕底部居中，宽度上限 68%，屏幕边缘留 12px。窄屏下 MAX 最低 12 与宽度上限冲突时，保留设置数量，通过横向滚动／溢出入口访问，不能挤出屏幕。数字设置在某屏超过该屏 MAX 时，仅对该屏自动夹紧，保留用户配置供大屏使用。
数量指显示槽位；手动固定项目超过槽位时仍保留，溢出“更多”按钮占一个槽位。可用项目不足时不制造空白图标。屏幕断开／接入、分辨率或 DPI 改变时重新计算。只有原本存在系统任务栏的屏幕显示快捷栏。

## 手动固定、推荐与移除
拖入桌面框内项目或资源管理器里的程序、快捷方式、文件、文件夹，会固定原路径的引用，不移动或复制源文件，也不在拖入时启动项目。手动固定项目优先显示并支持拖动调整顺序；同一路径不重复固定。固定与排除记录全屏共享，各屏按自身容量显示。
推荐来源仅是经 DeskBox 打开的桌面应用／应用快捷方式，在本机保存成功发出启动请求的频率与最近使用时间，使用半衰期约 14 天的时间衰减评分。第一版不通过全局窗口跟踪推测其他软件的使用，不保存额外的完整活动日志，不上传数据。鼠标停留、菜单打开或拖动期间冻结推荐排序，避免图标移位。
右键“从快捷栏移除”只移除栏内引用，并排除该项的自动推荐，不能调用文件删除／回收站接口。推荐项目因此不会立即回来。显示一次可撤销提示；再次手动拖入同一项会解除排除。移除固定项同样不动桌面文件。失效固定路径保留并提示不可用，失效的推荐目标跳过。

## 任务栏接管与恢复
启用前记录所影响任务栏的可见性、自动隐藏状态和所属显示器，只有快捷栏及恢复守护准备成功才隐藏系统任务栏。主程序与守护进程均不要求管理员权限。使用公开 Windows 窗口/AppBar 接口，不注入 Explorer、不终止 Explorer。工作区预留不能重复扣除原任务栏区域，也不能遮挡最大化应用的内容。
关闭设置、正常退出时恢复原状态并取消快捷栏工作区。守护进程监听当前实例生命期，主进程崩溃后恢复。Explorer 重启后重新定位任务栏，避免使用失效 HWND。持久恢复记录与实例身份绑定；启动时先处理遗留恢复状态再应用新配置。断电或同时强制终止主程序与守护时无法承诺即时恢复，下次启动时恢复遗留状态。
快捷栏不抢键盘焦点，普通窗口下可访问；全屏避让按显示器判断，全屏期间保护区域仍保留，避免文件夹框跳动。设置窗口仍可关闭开关；悬浮球菜单可提供恢复系统任务栏的快捷入口。

## 保护区域
启用后，在每个快捷栏所在屏幕底部预留栏高度与 12px 等距留白。用原生工作区约束防止普通最大化窗口被栏覆盖，同时在 DeskBox 几何计算中共享有效边界。文件夹框、合并外框及小组件的移动、调整大小、自动整理、合并／分离和布局还原均不能覆盖预留区；前端预览与后端落盘规则一致。
启用时已经冲突的框向最近可用位置调整；必要时按现有最小尺寸与排布规则缩放／整理，不删除内容。保护只在该开关开启时生效。关闭后释放边界，不强制把用户已经移动过的框跳回旧位置。无法满足屏幕最小尺寸时，使用已有可滚动内容和边界夹紧，保持栏可访问。

## 主题与动画
底座沿用主题色、透明度、圆角与阴影；高对比／减少动态效果下使用清晰静态边界。
- 显示／隐藏：约 220–260ms 的淡入上浮或淡出下移，轻微缩放，不反复弹跳。
- 悬停：图标抬升约 6px、放大至 1.08，约 140ms；显示名称提示，不推动实际命中区域。
- 点击：约 80ms 按压至 0.92 后恢复，启动请求成功时一次短光点；不假装监测软件完整启动或运行状态。
- 拖入固定：相邻图标约 160ms 让位，新图标约 240ms 缩放落位与一次主题描边高亮；拖离则收回预览，文字明确“固定到快捷栏”。
- 移除／撤销：约 140ms 缩小淡出与 180ms 邻项收拢，业务操作立即生效。
- 碰到保护边界：一次约 300ms 的主题边缘提示和轻量吸附反馈；位置始终有效，不允许预览覆盖栏。
- 数量调整：约 220ms 平滑改变底座宽度；排序只在非交互时平滑换位。
所有效果遵循现有 animSpeed 与系统减少动态效果，后台／全屏时暂停，无常驻粒子和持续流光。
