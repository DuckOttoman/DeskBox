# DeskBox 插件第一版设计规范

## 已确认目标
设置新增「插件」。支持通过 HTTPS URL 或本地 .deskbox-plugin 文件安装外观与 HTML/CSS/JS 小组件，提供安装预览、启停、卸载、手动检查更新、开发 SDK、示例及打包校验工具。市场目录作为独立配置 URL；第一版不运营账号、付费、评论或审核服务器。

## 包格式与兼容
插件包为 ZIP，根目录必须有 manifest.json，apiVersion 为 1。必需字段为 id（反向域名、小写字母数字与点横线）、name、version（三段数字）、author、type（theme/widget）、minDeskBoxVersion。widget 指定 entry；theme 指定 theme.json。description、homepage、updateUrl 可选。permissions.network 为允许访问的 HTTPS origin 列表；storage 默认为仅插件自身的数据空间。ID 不随版本改变。
限制：压缩包 20 MiB，解压总计 50 MiB，最多 512 文件，单文件不超过 10 MiB。不接受绝对路径、上级目录、链接、重复路径、大小写碰撞、Windows 保留名称或可执行文件；全部校验完成后才发布到安装目录。

## 安装和更新
下载限制 HTTPS、超时及体积；重定向后仍需验证协议。下载或选择本地文件后只生成暂存预览，不运行代码。预览显示名称、作者、版本、类型、来源与权限，用户点击安装才提交。来源与作者是发布者自述，不冒充已验证身份。当前版本保留至新版本验证、替换成功，失败恢复旧版本。按 ID 管理插件，禁止一个 ID 覆盖另一插件数据。启用状态、来源和授权保存在独立插件注册表，不混入桌面文件分类。
更新描述通过 updateUrl 获取 JSON，包含 id、version、url、sha256。手动检查更新；安装更新重新显示版本和权限变化。未知 API 或不满足最低宿主版本时拒绝安装。

## 外观
theme.json 仅允许固定的主题变量映射，颜色、圆角、边框、阴影、字体及插件资源背景。宿主将变量映射到现有文件夹框、小球、快捷栏和内置小组件。资源引用只能指向包内文件。第一版不允许任意 CSS 注入宿主页；避免主题改变命中区域、隐藏设置或覆盖系统交互。一次启用一个外观，停用恢复原主题。外观包不执行脚本。

## 小组件隔离与 SDK
小组件使用 sandbox iframe，允许脚本但不允许同源、顶层导航、弹窗或直接宿主命令。插件资源通过宿主生成的受限文档加载；CSP 禁止插件任意网络及外部代码加载。宿主对 postMessage 验证 iframe 的 contentWindow、实例标识、消息结构和大小，每个实例的能力来自已安装 manifest 与授权。
SDK v1 提供 ready、getTheme、onThemeChange、onResize、getSettings、setSettings、getSystemMetrics 和 fetch。fetch 经宿主代理，仅允许已授权 HTTPS origin，禁止本机、私网、链路本地和元数据地址，重定向逐跳检查；限制超时、响应大小和并发。系统指标只返回现有采样结果，不启动程序或提升权限。设置数据每插件最多 256 KiB。禁止文件系统、Shell、任意 Tauri invoke、读取其他插件数据。
宿主沿用现有小组件的位置、尺寸、拖动、菜单及布局备份；向插件发送逻辑像素尺寸、small/medium/large 形态和可见性。隐藏时通知暂停，停用或卸载立即销毁实例。错误显示组件内错误卡片，可通过宿主菜单移除，不影响其他小组件。

## 管理界面与目录
插件页有市场、已安装和开发帮助；始终提供 URL 安装和本地导入。已安装项显示类型、版本、作者、权限、来源、状态，支持启停、检查更新、卸载。卸载默认保留独立设置，可勾选删除插件数据。组件插件安装后出现在「添加小组件」中。停用时保留布局条目并显示占位，重新启用恢复。
市场目录为 schemaVersion=1 的 JSON，entries 包含 id、name、description、author、type、version、url、sha256。目录无配置时显示说明并可直接安装；不使用虚构的官方市场地址。目录展示内容只按文本渲染。

## 开发交付
提供 docs/plugins.md 和英文对应文档、manifest 与目录 JSON 示例、SDK API 文档、主题与时钟小组件示例，以及 Python 打包校验工具。工具验证与运行时遵循相同限制，输出可直接通过本地导入或 HTTPS 安装的 .deskbox-plugin 文件。

## 验证与交付标准
测试恶意 ZIP 路径、大小写碰撞、解压上限、不兼容 API、失败更新回滚、数据隔离、伪造消息、网络权限与私网拒绝。验证示例插件从打包、预览到安装、添加组件、缩放、保存、重启、停用、卸载的完整流程；主题覆盖与恢复、布局备份不回滚插件私有内容。执行 Rust 与界面回归，验证现有快捷栏拖动和任务栏恢复；通过后重新编译并交付更新包及联网、离线安装包。

## 工程约束
源码目录当前没有 Git 元数据，不能在这里创建可审查的 Git 提交；保留文档和变更记录，不向其他隐藏仓库提交或推送。不得覆盖正在使用的安装目录或个人配置，原生验证使用隔离测试目录。
