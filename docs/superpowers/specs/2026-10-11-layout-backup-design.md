# 布局备份与还原设计

- 悬浮球右键添加「布局备份」「还原备份」。备份默认使用日期时间命名，创建后提示成功。
- 「还原备份」打开跟随主题的管理面板，按时间列出名称、明确显示的备份时间（年月日时分秒）、文件夹框及小组件数量。每项提供还原、重命名、删除；删除需明确操作确认，重名允许，空名拒绝。
- 备份保存在应用用户数据目录，原子写入，重启保留。写入失败保留已有记录，显示错误。
- 记录文件夹框名称、分类、显示器、位置、尺寸、样式、背景引用、卷起/隐藏状态，记录外框合并组成员、当前成员和组位置。
- 不保存文件清单、桌面文件本体、手工文件归属历史或内容合并还原点。还原依据当前桌面扫描结果及当前分类学习规则重新分类；现有桌面文件不增删移动。无法匹配分类的文件进入收纳框，避免丢失显示。
- 记录小组件类型、位置、尺寸、样式及设置（天气城市、计时参数、相册播放设置等）；不回滚便签文本、待办完成状态、正在运行的计时状态、相册图片清单或天气缓存。同一组件仍存在时保留其当前内容；已删除组件恢复为同类型空内容/默认运行状态。
- 背景仅保存引用，不复制大视频。引用不存在时回退普通背景并提示。
- 还原替换当前框及小组件布局，备份本身保留。还原前自动保存当前布局为「还原前自动备份」，用于恢复操作前布局。
- 显示器仍存在时使用记录坐标；缺少显示器时映射到主屏并限制在可见区域。还原结束刷新穿透区域与状态。
- 不包含全局开机启动、分类学习历史或悬浮球位置的回滚。

## 验证
测试备份不含文件清单；还原保持当前桌面文件集合和当前小组件内容；外框组位置/属性恢复；显示器缺失不产生屏外窗口；重命名/删除/重启持久化；并验证主题管理面板与悬浮球菜单。最终提供联网安装包、替换更新 ZIP 和源码。
