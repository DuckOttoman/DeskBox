# DeskBox 插件与市场实施计划

目标：实现已确认插件 SDK、安装管理与用户授权服务器上的只读市场。
环境：本地源码无 Git 元数据；原目录开发并保留证据，不推送。服务器 47.85.175.203，root SSH 已授权，密码仅交互使用，不存储。

1. 包与注册表：src/plugins.rs 定义 manifest、版本、权限、ZIP 限制、暂存预览与原子安装；先测试路径穿越、碰撞、体积与更新失败回滚，再实现。插件数据独立于布局。
2. 命令与网络：src/plugin_runtime.rs 注册安装、启停、卸载、目录与更新命令；网络逐跳校验 HTTPS、公网 IP、域名权限与响应上限，测试私网、重定向及权限拒绝。
3. 宿主与设置：ui/plugins.js/css 提供插件管理；沙箱 iframe 与逐实例消息绑定隔离插件命令。测试伪造消息、停用销毁、主题恢复和尺寸事件；通过 tools/patch_frontend.py 接入设置和添加组件。
4. 开发交付：docs/plugins.md、docs/plugins.en.md、examples/plugins 与 tools/package_plugin.py；示例主题和时钟插件经过相同校验并端到端安装。
5. 市场：server/market 提供静态 schemaVersion=1 目录、带版本包路径、SHA256 和发布校验；公网仅只读，没有上传接口。独立目录、非 root 服务、systemd 托管。先回环测试，再启用受信 HTTPS 公网服务。无域名时不静默降为 HTTP；评估公网 IP 证书可用性，否则等待域名。
6. 验证与交付：执行插件安全测试、Rust 和现有界面回归、隔离原生安装测试，再编译更新包与两种安装包。实测服务目录与包哈希匹配；不自动覆盖用户运行中的程序。

当前：SSH 连接通过；系统 CentOS 7，22/8888 监听，80/443 未监听。域名尚无，现有服务需保留。
