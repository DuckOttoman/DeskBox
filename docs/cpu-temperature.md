# CPU 核心温度

系统状态小组件右键 → CPU 温度：最低核心温度、最高核心温度、同时显示最低与最高。每个组件单独保存；默认最高。读数是当前采样的有效核心范围，不是启动以来的历史极值。

安装版首次启用：右键 → CPU 温度 → 启用／重试温度采集，确认 Windows 授权。主程序无需管理员运行；服务按需启动，空闲约一分钟退出。拒绝授权后其他功能继续使用，可在同一入口重试。

便携版会请求独立采集进程权限，并从受保护的 Program Files 目录运行采集器。同一管理员账户的普通权限启动和提升采集已验证；标准账户使用另一管理员凭据的便携模式尚未验证，建议此场景使用安装版服务模式。

传感器未提供逐核心读数、组件缺失或读数过期时显示不可用；封装温度、ACPI 热区作为明确标注的补充提示，不能替代逐核心最小／最大值。不同 CPU 提供的传感器种类不同。

采集组件：LibreHardwareMonitor 0.9.6、PawnIO 2.2.0；仅启用 CPU，主程序本地连接只读管道，不开放网络端口。服务位于 Program Files/DeskBox Sensor，普通用户只有读取执行权限。安装程序保留必要 Windows 授权提示并隐藏控制台；卸载时可以选择移除全局采集服务，PawnIO 可能被其他软件使用，因此不会自动删除。

更新时复制整个更新包，包括 sensor-tools。若此前启用过旧采集服务，更新后从右键入口重新启用以更新全局服务文件。
