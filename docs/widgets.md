# 桌面小组件

小球右键 → 添加小组件，提供时间、系统状态、倒计时与番茄钟、便签与待办、相册。拖动标题栏移动；拖右边、下边或右下角调整尺寸，松开保存。宽度至少420且高度至少280个逻辑像素为大号，宽度至少280且高度至少190为中号，其余为小号。Windows缩放下采用CSS逻辑像素，保持可读性。最小180×100，最大1200×1000。

时间小号显示时间、日期和当前天气；大号展开三天天气。右键选择城市并搜索，点击搜索结果确认。Open-Meteo提供数据，15分钟刷新，12秒请求超时；离线时保留最近缓存并标记。通过菜单访问数据来源。使用天气需要联网，其余组件可离线使用。

计时器支持倒计时与番茄钟切换，专注、休息、倒计时时长均可设置。运行状态用绝对截止时间保存，暂停记录剩余时间，重启继续计算。结束时声音和桌面气泡提示；专注结束后准备休息，手动开始下一阶段。程序完全退出期间不发送提醒，重新运行后处理已到期计时。

便签自动保存，待办输入后回车添加，勾选完成或点击×移除。中号提供便签和待办，大号展开更多内容，小号以便签和待办数量为主。点击输入区域可获得原生键盘焦点，不触发拖动。

相册右键添加图片、管理图片/轮播、更换目录、开始/暂停轮播及设置填满裁切/完整显示。默认存放在可执行程序所在目录的 `Albums/<组件ID>`；桌面目录禁止使用，目录不可写时请通过菜单选择其他目录。PNG/JPEG/WebP/BMP导入为最长边不超过2560像素的PNG展示副本，原文件保持不变，每个相册最多200张。默认8秒轮播，支持2至3600秒。组件隐藏时不推进轮播，展示只加载当前图片。移除播放条目、更换目录或删除组件会保留已有展示副本；卸载也保留相册与配置，避免误删个人内容。旧目录可在确认新目录图片正常后自行清理。

系统状态保留原采样功能；小号显示简要指标，大号展开统计，尺寸随拖动变化。显存采用与内存相同的标题行、已用 / 总量 GB（保留一位小数）和主题用量条；未知已用量显示“—”。

## 天气 Emoji、IP 定位与内存优化

中型和大型显示天气 Emoji，大型预报也显示对应图标，小型保持简洁。新建时间组件时通过 HTTPS 向 ipapi.co 请求公网 IP 的大致城市，失败后尝试 ipinfo.io；服务会收到请求的公网 IP，应用只保存城市、近似坐标和来源，不保存 IP。定位可能受 VPN/代理影响；都失败时可右键手动选城市。已保存或手动城市不被自动覆盖。

小球右键“内存优化”使用 Windows 工作集回收，只处理 DeskBox 及其连续 WebView2 子进程，不终止进程、不影响其他应用、不改变视频原画设置。报告即时工作集变化，内存会因后续访问重新载入，不等同于永久释放或显存清理；10秒内重复点击会提示稍后重试。

## 布局备份

悬浮球右键选择「布局备份」保存当前框和小组件布局，默认以时间命名。「还原备份」打开管理面板，每项显示备份名称、备份时间和数量，可还原、重命名或删除（再次确认删除）。还原前自动备份当前布局。备份不包含桌面文件清单，还原时按当前桌面分类；便签、待办、相册内容和计时运行状态不回滚。已删除的小组件还原为空内容，缺失显示器映射主屏，缺失背景回退普通背景。
