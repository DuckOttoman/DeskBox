# 快捷访问栏

在悬浮球的“设置 → 行为”中启用“隐藏任务栏”。每个原本有 Windows 任务栏的屏幕显示一条 DeskBox 快捷访问栏，关闭开关或退出应用后恢复系统任务栏。悬浮球右键根据当前状态提供“隐藏任务栏”或“恢复任务栏”，可反复切换。默认关闭。

普通窗口下保持可访问；某屏幕被全屏应用覆盖时，仅隐藏该屏幕的快捷栏。此时仍保留工作区，避免桌面布局反复跳动。Windows 的最大化工作区与文件夹框、小组件共享同一预留边界，底部留出栏高和上下各 12 个逻辑像素的间隔。

拖入应用、文件或文件夹可以固定，也可以从 DeskBox 文件夹框直接拖入。这里只保存路径引用，不复制、移动或删除源文件。固定项目优先；右键“从快捷栏移除”会同时排除自动推荐，可以在提示中撤销，重新拖入也可以恢复。路径失效时保留固定项并显示不可用标记。固定项可以拖动排序；超过显示槽位的项目放入“更多”。

推荐仅根据通过 DeskBox 成功提交的桌面应用或应用快捷方式启动请求累积，不监视其他应用的使用行为，不保存逐次启动日志。分数按约 14 天半衰期衰减。普通文档和文件夹支持手动固定，不进入使用习惯推荐。

数量可设为 10 到 MAX，默认 12。每屏 MAX = max(12, floor(屏幕逻辑宽度 × 68% / 72))；一个图标单元为 60px，间距 12px。选择 MAX 后随显示器调整。小屏仍限制底座不超过屏幕宽度的 68%，通过“更多”访问剩余项目；不会丢弃固定项。

底座跟随主题、透明度、磨砂与动画速度。提供进入、悬停抬升、按压、启动描边、固定落位、移除收拢和宽度变化动画；减少动态效果或高对比模式会简化效果。没有持续粒子动画。

## 恢复机制与范围

接管前记录原任务栏的可见性、自动隐藏状态和显示器，等待快捷栏及独立恢复守护就绪，再使用公开 AppBar API 预留工作区。独立原生透明窗口承担工作区预留，避免菜单窗口高度改变预留空间。必须回读实际 Windows 工作区并确认稳定，否则恢复原任务栏并报告失败。

正常关闭会取消预留并恢复；主程序异常退出时，独立守护进程执行恢复。断电或同时终止主程序与守护时，无法即时恢复，下一次启动读取遗留恢复记录处理。此功能不需要管理员权限，不注入或终止 Explorer。

显示器连接、分辨率或 DPI 变化会重新建立快捷栏和预留区。Explorer 重建后重新定位任务栏并登记 AppBar。当前机器上的原生验证结果见 `evidence/quickbar-verification.json`；没有实测的硬件组合不能视为已验证。
