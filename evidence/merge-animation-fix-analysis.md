# 内容合并动画修正

按用户截图与明确要求修正三处显示问题，数据合并规则保留：按住五秒仅预览，松开左键才提交。

根因：旧动画把 `.item` 副本改成页面顶层 `.db-merge-particle`，不再继承文件夹框的 `--icon-size`、主题、原样式和150%缩放；落点固定为五列、70px间距，既不读取目标现有文件数，也不匹配真实网格。取消时另建顶层返回副本，形成短暂框外显示和重复图标。

实现：把无数据ID、不可交互的 `.item.db-merge-slot` 副本追加到目标真实 `.grid`，继承目标框的图标尺寸与主题，浏览器负责续排与换行。在目标放大后测量真实格子，按源位置换算位移和初始缩放，最多40个同时流入。已流入的格子留在自己的目标位置，后续批次接在它们后面。排除目标已有同ID项目，不改实际文件列表。

取消：同步取消动画、删除所有预览格子、恢复源真实图标可见性及目标/邻框样式，然后只缩小销毁气泡；没有框外返回副本。

回归：`tests/merge-animation-webview.js` 使用源4项/24px、目标3项/64px的独立文件，验证预览追加在真实项目后，第一格跟随最后一格、图标尺寸与目标一致、无页面顶层粒子、取消同步恢复源框。旧版在 `preview_slots_append_after_existing_items` 断言失败，见 `animation-fix-red-final/runtime.log`。首轮诊断因前端初次订阅尚未完成而超时，测试等待初始状态稳定后重跑，未当作功能失败依据。

布局与状态使用原生 WebView 验证；完整物理鼠标长按、多屏不同DPI与逐帧视觉验收仍需实测。
