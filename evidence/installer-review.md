# Installer delivery review

Built workspace-local NSIS current-user Windows10/11 x64 setup. Verified application payload unchanged from icon-name/radius delivery, including FFmpeg and its notices. Microsoft WebView2 standalone x64 runtime embedded after Authenticode Valid/Microsoft Corporation verification. Microsoft offline distribution and registry detection docs consulted; installation fails if runtime still absent after installer executes. No global compiler installation.

Contract tests red: missing installer file. Green: scoped user installation, runtime guard/detection, required payload, shortcut/uninstall metadata, no recursive uninstall or forced taskkill. Actual diagnostic variant compiled from same installer source using distinct registry/shortcut/autostart names. Executed installation in workspace-owned directory, including Chinese and spaces; payload hashes, shortcuts, registry, locked-file upgrade rejection, successful reinstall with sentinel preservation, installed media/GIF/mode/menu/radius checks and normal temp-copy uninstaller all pass. Own matching --autostart value is removed, shared runtime and generated configuration/sentinel are preserved. Production setup differs in display/key names only. Source and default payload do not contain the development computer's configuration or files.

Initial installed-app diagnostics failed on an unnecessary programmatic native keyboard-focus request. Removed that request from installer diagnostic driver; actual menu/playback tests subsequently pass. Production app binary is unchanged.

PE dependency audit for app/loader/FFmpeg confirms x64 binaries and system DLL imports plus bundled WebView2Loader, without Rust/Node/Python dependencies on destination PC. Build produces unsigned setup: no certificate was provided. Missing-runtime branch uses genuine offline installer but was not executed on a clean Windows VM; no claim of separate-computer testing or x86/ARM native support. Local verification results: installer-verification.json and installer-payload-imports.json.
