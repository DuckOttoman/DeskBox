# 文件夹框组合与内容合并

本功能为用户批准的新交互，不是原版逆向还原项。设计见 docs/superpowers/specs/2026-10-10-fence-merge-design.md。

## 实现

- Config 添加默认空的 fenceGroups、mergeRestores。保留独立 Fence 和 Item ID，磁盘文件不移动。
- src/fence_merge.rs 负责组合、选择成员、分离、内容合并、逆序还原、重命名映射、删除清理和有界避让。命令通过 AppState.mutate 克隆、保存成功后替换并广播。
- group_fences、select_fence、detach_fence、merge_fence_contents、restore_fence_merge 注册到 Tauri。合并检查实际 WebView 显示器，包括主屏断屏回落。
- ui/fence-merge.js 拥有独立指针状态机。5000ms 使用 performance.now，与动画速度无关；定时器只改变视觉效果，只有匹配左键 pointerup 才调用合并命令。pointercancel、Esc、失焦和移出清理预览。
- 标题单击切换成员，拖动达到阈值后才捕获指针；分离在空白处松手提交。拖动期间原生命中范围扩大，忙碌标记保护位置不被状态刷新覆盖。
- 主题高亮、动态流彩边缘、气泡、150% 放大、邻框 10% 临时透明度及图标排队通过动画层实现。图标仅用副本分批展示，最多 40 个同时流入。取消恢复原样式并移除副本。
- 内容合并追加顺序并去重，目标属性保留且不改学习记录；右键标题加入“还原内容合并”子菜单。还原继承目标当前属性及两个原名称，消费还原点，保留后来加入的文件且不抢回已移出项目。
- 完整整理只布局每个可见组合一次；还原布局解析实际组合显示器及断屏回落，避让邻框，并尽量选择空间更大的方向。空间不足时使用有界的最低重叠候选布局，不宣称全局最优。

## 复核修正

复核发现并修正：标题点击过早捕获指针、扩大目标后按 DOM 顺序错误切换到遮挡邻框、完整整理未更新组合容器及隐藏成员空位、还原遗漏主屏断屏回落邻框、取消时多余正向动画副本。后端二次复核无重要或阻塞问题。

## 验证边界

Rust 核心测试覆盖持久化、属性、列表分区、LIFO、后续移动/删除/重命名、组合成员和拥挤布局。Node 模拟指针覆盖按住超过五秒不调用提交、右键松开无提交、取消无提交及两种左键松开。原生 WebView 的测试指针为 DOM 注入（capture 仅在诊断驱动中替代），不是物理鼠标；检查实际接口保存及渲染状态。

完整真实鼠标长按、桌面父窗口上的动画和多屏不同 DPI 尚未验证，不以模拟测试代替实测。主题流彩与150%效果已编码，逐主题像素验收尚未完成。
