# Media backend implementation report

Implemented `src/media.rs` exported by lib.rs, expanded picker and diagnostic import/mode/clear/policy commands, and low-overhead native fullscreen/power/input-desktop policy.

Public API: `MediaBackground {kind:String, original:String, eco:Option<String>, poster:String, mode:String}` serde camelCase; `prepare_background(source:&Path, managed_dir:&Path, ffmpeg:&Path)->Result<MediaBackground,String>`; `MediaBackground::validate_mode(mode:&str,managed:&Path)`; `ffmpeg_path(diagnostic:bool)`; `is_animated(&Path)`.

Commands: existing `pick_fence_image(app,data,id)` async, `import_fence_background(app,data,id,source)` async diagnostic-only, `set_fence_video_mode(app,data,id,mode)`, existing `clear_fence_image(app,data,id)`, `media_playback_allowed()->bool`. Controller must register three added names in app.rs. style.image is poster, style.media is object. Static images retain PNG conversion and remove media. Mode switching performs no encoding and validates selected file/poster canonical paths inside managed backgrounds.

Managed import uses UUID staging, immutable original copy, checked FFmpeg exit status, nonempty outputs, one-frame eco decode validation, rename after preparation, failure staging cleanup. FFmpeg uses decoder, filter, encoder thread limits 2 and Windows CREATE_NO_WINDOW. Video eco libx264/yuv420p MP4 no audio <=854x480 without upscaling; source fps clamps 24–30, unknown30. Source never written. Preparation mutex is acquired on blocking worker. Save verifies fence existence and unchanged media/image; late overwritten import is discarded. Saved import is retained if publish alone fails. Path override DESKBOX_FFMPEG allowed only in diagnostic mode.

Evidence: media-backend-red.log captures preimplementation failure missing exported media module. This is a compile-level missing-API red, not a runtime assertion red. Five focused tests added. Full core suite `python tools/cargo_local.py test --no-default-features --locked` passed with DESKBOX_FFMPEG_TEST actual bundled FFmpeg. Real video fixture 1280x720 60fps with AAC produces H264 854x480 30fps silent eco; FFmpeg sets SAR1280:1281 preserving DAR16:9. Original bytes equal fixture bytes. Real animated GIF original bytes retained/default original/no eco. Corrupt input errors clean staging; unsupported input avoids staging; invalid/missing variants reject.

GUI `python tools/cargo_local.py check --locked` passed. At time of check new unregistered command functions emit dead-code warnings until controller registration; no backend compilation errors. Logs: media-backend-core.log and media-backend-gui-check.log. Native UI actual playback/persistence, battery saver/lock behavior, packaging notices, source switching and frontend lifecycle remain controller work. No release build performed.
