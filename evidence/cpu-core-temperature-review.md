# CPU core temperature review (2026-10-15)

User approved instantaneous per-core minimum/maximum/both modes, independent per-widget persistence, an on-demand installed service and portable elevated collector. CPU-only LibreHardwareMonitor 0.9.6 and official PawnIO 2.2.0 installer are pinned by official release digests; licenses/notices accompany binaries.

Independent source review found and fixed staged payload verification races, disconnected client exceptions, partial pipe framing, portable retry mapped-executable replacement and asynchronous uninstall helper deletion. Elevated staging verifies the actual protected copies against embedded dependency hashes and caller-pinned helper digest before installing executable service payload. Program Files directory grants users read/execute, with full control only for administrators and SYSTEM. Pipe exposes CPU data only, denies network clients and grants users read access; there are no privileged request verbs.

Native testing found SYSTEM process identity lookup denied to the ordinary client. An attempted process-DACL change was rejected by automatic approval and never executed. The implementation instead authenticates installed pipe PID and quoted protected ImagePath through the Windows service manager using existing read/start permissions. No process-security change was made. Portable mode checks its protected executable path; same-account elevated portable mode and repeated enablement passed. A standard account supplying another administrator's credentials in portable mode is not verified and is documented as a limitation; installed service mode is recommended there.

Real hardware samples on i7-13700K contain sixteen current core values and change between sampling rounds, unlike the stationary 301 K ACPI zone. Invalid/expired values clear temperature. Frontend native tests caught missing dynamic VNode flags on the custom temperature fields; these were added and modes plus real displayed values were retested. Cancellation feedback now catches rejected enable requests and avoids reporting success.

Normal configuration/desktop and normal installed application were not replaced during diagnostics. A machine-wide DeskBoxCpuSensor service was installed and left available, demand-start with approximately 60 seconds idle exit. Shared preexisting PawnIO was retained. Installer tests use isolated paths and skip elevation; service install/remove/reinstall and portable retry were tested independently. No GitHub upload in this task. AMD hardware, missing-runtime clean VM, alternate-administrator portable elevation, and real-user cancellation prompt were not physically tested; cancellation UI rejection was tested using a simulated invoke failure.
